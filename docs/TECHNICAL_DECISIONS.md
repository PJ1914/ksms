## Phase 3 decisions (2026-11-18)

| ID    | Decision                                                                                                                                    | Rationale                                                                                                                                                                                                                                                                                                | Status  |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------- |
| TD-23 | **NestJS 11.2.10 (CommonJS)**, not Nest 12                                                                                                  | Nest 12 (released 2026-08-27) is ESM-only. That forces ESM everywhere (`.js` import extensions, experimental Jest ESM) with little benefit for this project. Nest 11 is the maintained `legacy` line and works with ts-jest, Swagger 11 and Prisma CJS. Revisit via ADR when ESM test tooling is settled | Decided |
| TD-24 | **TypeScript 6.0.3** repo-wide; `module`/`moduleResolution` = `node16`                                                                      | TypeScript 7.0 conflicts with peers of ts-jest (<7), typescript-eslint (<6.1) and @nestjs/swagger (^5.5 or ^6). TS 6 deprecates `node10` resolution and `baseUrl`                                                                                                                                        | Decided |
| TD-25 | pnpm 12 with `node-linker=hoisted`, `saveExact`, and `allowBuilds` limited to `@parcel/watcher`, `@prisma/engines`, `prisma`                | Metro needs a flat `node_modules`; reproducible installs; pnpm 12 blocks dependency install scripts unless approved                                                                                                                                                                                      | Decided |
| TD-26 | No `docker-compose.yml`; local DB is a Neon dev branch (TD-10). CI uses a throwaway `postgres:17` service container for the migration check | Docker not installed and not needed                                                                                                                                                                                                                                                                      | Decided |
| TD-27 | NativeWind (TD-06) is **deferred to the first real UI phase**; Phase 3 shell uses plain `StyleSheet` + a small token file                   | Avoid unused styling-toolchain risk before screens exist; NativeWind setup is verified together with the first real screens                                                                                                                                                                              | Decided |
| TD-28 | Expo packages keep Expo's `~` ranges (managed by `expo install`); all other dependencies are exact                                          | Expo SDK compatibility is defined by the SDK; do not hand-edit                                                                                                                                                                                                                                           | Decided |
| TD-29 | Android application id is a placeholder `com.ksms.storemanager`                                                                             | Can be changed freely until the first Play Store upload; **owner should confirm the final id before publishing**                                                                                                                                                                                         | Open    |
